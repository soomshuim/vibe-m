### A.2 글로벌 Dry vs Tuned Rage Trap 비교

#### A.2.1 보컬 디자인 비교표

| 항목 | **Dry Voice Rage** | **Tuned Singing Rage** |
|------|-------------------|----------------------|
| 대표 (US) | Playboi Carti `Whole Lotta Red` (2020), `Music` (2025), Yeat 일부, Ken Carson | Travis Scott `Astroworld` 톤, Don Toliver `Hardstone Psycho` (2024-06), SoFaygo, Destroy Lonely |
| 보컬 메인 처리 | **Distortion/saturation + 고함량 reverb + extreme EQ shape** (autotune은 보조) | **Antares Auto-Tune** + 빠른 retune + soft reverb tail |
| Retune speed | 가변 (Carti는 자료마다 다름, 0~30ms / Yeat는 0-10ms 극단) | Travis Scott 0-10ms (retune fast) / Don Toliver 5-12ms (notes bend & wobble) |
| Formant | Carti = baby voice 시 +2~+4 semitone | Travis Scott = 거의 안 건드림 / Yeat = 형식 변형 핵심 무기 |
| Reverb | Carti = 의도적 짧고 raw / Yeat = static decay <1초 | Travis Scott = **Slate Verbsuite Classics, Large Halls, "cathedral reverb" / 길게** |
| Distortion 위치 | 1-6kHz 의도적 saturation (Yeat "static autotune") | 적용하더라도 vocal에는 절제, 비트에 집중 |
| 가창성 | Screamed / yelled / gutteral / chant — **not melodic** | **Sing-rap melodic hook 중심** |
| Ad-lib | Carti = 인디스팅 시그니처, 수십 레이어 / 무전제 압축 | Travis Scott = 멜로디 셋업으로 ad-lib도 음정 보유 |
| 마스터링 | -6 LUFS 수준 brick-walled, blown-out | -7~-8 LUFS 더 정돈, dynamic 보존 비교적 큼 |

#### A.2.2 프로덕션 기법 차이

| 항목 | Dry Rage | Tuned Rage |
|-----|----------|-----------|
| Vocal sample 사용 | 적음 — 보컬 자체가 비트의 일부 | 많음 — Travis Scott "intro vocal loop" 시그니처 |
| Hi-hat 밀도 | 1/16 + 32nd triplet roll, 변화 큼 | 비슷하나 **groove 보존 위해** 약간 절제 |
| 808 처리 | Hard clipping, blown-out | Saturation은 같지만 **portamento 멜로디성** 강조 |
| 신스 팔레트 | Detuned supersaw + FM bell 강함 | Detuned supersaw + **pad/atmosphere 레이어** 더 두꺼움 |
| 곡 구조 | Verse-chorus 해체, chant 위주 | **Melodic chorus 명확** (verse-chorus 보존) |

#### A.2.3 2024-2026 글로벌 트렌드

- **Carti 2024 변화**: `2024` 싱글 + Travis Scott `FE!N` 피처에서 **deep tonal voice** 도입. autotune이 아니라 **bronchitis-like 깊은 톤** (Pitchfork) — Dry Voice 진영의 **새로운 진화**
- **Don Toliver `Hardstone Psycho` (2024-06-14)** — Tuned Rage 진영의 정점 작품. "auto-tune to its limits, INSIDE 트랙 90s R&B vibes + 멜로디"
- **Yeat `2093` (2024-02-16)** — **electro-rage** 자가 분류. Tuned이지만 "extreme robotic" → Travis Scott형과 다른 alien 라인
- **차트/스트리밍 우세**: Travis Scott 주류성 + Don Toliver 차트 진입력 → **Tuned 진영이 메인스트림 주류**. Carti는 컬트적 영향력으로 SoundCloud/Cult fanbase 우위.

> **인사이트**: Korean KC Rage의 vangdale 광택 디자인은 **Tuned 진영과 더 친화적**. Sik-K "sing-song rapping" 시그니처(NamuWiki 직접 인용) 또한 Tuned 라인. 따라서 **Korean Rage 씬은 본질적으로 Tuned 쪽으로 발달**한 것으로 해석. Wavvy가 Korean 가창 위주 시리즈라면 Tuned가 자연스러움.

#### A.3.4 EXCLUDE (NEGATIVE PROMPTS) — 양 진영 정체성 보호

**Suno V5 negative prompt 검증된 syntax**: `no [X]`, `without [X]`, `exclude [X]`, `avoid [X]`. `no` 형식이 가장 character-efficient. 프롬프트 끝에 배치 (Suno는 positive 먼저 처리).

| 진영 | EXCLUDE 키워드 | 이유 |
|-----|--------------|------|
| **Dry Voice 유지** | `no autotune, no pitch correction, no melodic hooks, no clean polished vocals, no falsetto, no formant shift` | autotune 흘러들어오면 Carti 아닌 Travis Scott 쪽으로 sliding |
| **Tuned Singing 유지** | `no dry shouted vocals, no raw screamed vocals, no blown-out mix, no punk vocal, no growl, no mumble rap` | autotune 빠지면 Tuned 정체성 상실. 또한 mumble rap 경향 진입 차단 |

#### A.4.2 Workout 콘텐츠 정합성

**Tuned Singing Rage 강점**:
- Melodic hook → **반복 청취 피로도 낮음** (Dry vs)
- "Anthem" 구조 → **set 사이 모티베이션 부스트** 자연스러움
- vangdale 광택 디자인 → **Spotify 알고리즘 친화적** (loud, polished, high energy)

**Dry Voice Rage 강점**:
- Raw shouted vocals → **strong moment 직격 (PR 시도, 마지막 set)**
- Sub bass blown-out → **헤드폰/이어폰 저음 임팩트 우수**
- Set up → 폭발 구조 → **HIIT 인터벌 적합**

**Tuned Singing 약점 (Workout 관점)**:
- Melodic hook이 **러닝 페이스 깰 수 있음** (Travis Scott `Goosebumps` 같은 mid-tempo 트랙은 부적합)
- 가사가 명확히 들릴수록 **운동 집중 방해** 가능 (한국어 가사면 더더욱)

**Dry Voice 약점 (Workout 관점)**:
- 13곡 연속 청취 시 **피로도 큼** (특히 Yeat alien tone)
- 한국 청자 25-35 직장인은 **순수 Dry Rage에 진입장벽 큼** (메인 리포트 §3.5 한국어 적용 리스크 검증)

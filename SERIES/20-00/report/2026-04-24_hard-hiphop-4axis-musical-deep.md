## 3. 축 1: Rage / Aggressive Trap — 핵심 발견

### 3.1 프로덕션 특성

**BPM 허브**: **140-160 (핵심 140-155)**, tread 지선 160-190
- 이중 템포 전략 보편화: Miss The Rage 77/154 halftime 재해석
- Yeat `2093` 앨범 단위 137/164/146 BPM 다변화

**드럼 & 808 핵심**
- Kick–808 **1:1 sync** (808 루트마다 kick 교체)
- Layered drum: Punch kick (80-200Hz 트랜지언트) + Bass drop (20-60Hz 서브 롱)
- Hi-hat: 1/8-1/16 기본 + 다운비트 직전 **32nd triplet roll** (Landr·emastered 검증)
- 808 moving bass: **long note + pitch glide (포르타멘토)** 기본. 루트→5도/단6도 크로마틱 슬라이드
- Saturation/clipping: 의도적 hard clipping 사용 (Mike Dean 원칙 "가만히 두는 게 최선"과 대립)

**신스 팔레트 (실존 프리셋)**
- **Supersaw Lead**: Serum/Vital/Sylenth1/Massive. FE!N 실제 레시피 검증(Syntorial A급): OSC1 Saw 80% / OSC2 Saw +1 oct 20%, Unison 2 voice 4-cent detune, Amp ENV A0/D1300ms/S60%/R20ms
- **Hyper-bright bell/FM bell**: Pi'erre Bourne가 Sledgren 영향으로 게임 사운드 샘플링 (The FADER)
- Pi'erre Bourne 메인 툴: **Sylenth1 + FabFilter Twin 2 + Native Instruments Absynth 5** (Equipboard)
- DAW: FL Studio → Ableton Live (Pi'erre 이전)
- **Prepackaged EDM melody packs** 빈번 사용 (Wikipedia A급: "EDM synth hooks in rage come from pre-packaged EDM melody packs")
- Cymatics "Odyssey Future Bass Drop Loop 7"가 Miss The Rage 샘플 (Whosampled 확인)

**믹싱 체인 (권장)**
1. EQ (mid/low 정리)
2. Saturator (Decapitator / Saturn / Trash) — tape warmth
3. Bit crusher — lo-fi (F1lthy 스타일)
4. Multi-band compressor — 2-5kHz 제어
5. Soft clipper -1dB
6. Limiter 1dB ceiling, **-7 ~ -5 LUFS 목표** (Spotify -14 대비 6-9dB 라우드)

### 3.5 한국어 Rage 적용 리스크

**한국어 음절 CGVC 구조** (Wikipedia 검증)
- 초성 + 중성 + 종성(선택) / 종성 허용 7개 (/p, t, k, m, n, ŋ, l/)
- 19 자음, 7 모음

**Rage 플로우 충돌 요소**
1. 받침 음절 = 자음 closure 증가 → 영어 "huh!"/"yeah!" 같은 오픈 애드립 한국어 대체 시 종성 걸림
2. Pitched-up baby voice에서 받침 왜곡 → 명료도 급감. Carti 스타일 "불명료 전제" 수용 필요
3. Triplet flow: syllable-timed 한국어에서 가능하나 받침 음절(밤, 길)은 무거움

**반론 근거**: Outsider 24 syllables/sec peak → 속도 자체는 문제 없음. Rage는 속도보다 **톤/질감**이 핵심.

**Female Korean Rage**: 현재 명시적 부재. Jvcki Wai가 가장 근접(emo-trap/hyperpop)

### 4.7 한국어 Drill 적용

- 한국어 = **Syllable-timed**. 음절 균등 발음이 기본 → 드릴 flat/monotone과 충돌 가능
- 해결: **된소리(ㄲ/ㄸ/ㅃ/ㅆ)/거센소리(ㅋ/ㅌ/ㅍ/ㅊ)** 악센트 활용 = menace 표현 자연스러움
- 받침(batchim)이 핵심 리듬 포인트 — 808 슬라이드·스네어와 동기화
- 연음 특성 덕분에 드릴 flow 이어붙임 용이

### 9.4 Articulation 호환성

- Wavvy 규칙: "Articulation. 필수"
- Suno 공식 메타태그: `[Staccato]`, `[Legato]` 포함되나 `articulation` 자체는 미검증
- **권장 병기**: `sharp articulation`, `clear diction`, `crisp enunciation`
- **주의**: `Articulation.` 마침표 형태는 토크나이저 분리자 오인 위험 → **마침표 없이 사용**

### 9.5 메타태그 전술

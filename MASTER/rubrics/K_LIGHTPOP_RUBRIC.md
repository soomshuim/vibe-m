## Evidence Basis

### 1. Light Pop vs Sweet Ballad 핵심 차이

| 항목 | Korean Light Pop | K-Pop Sweet Ballad |
|------|------------------|---------------------|
| 우선순위 | 캐치한 멜로디, 폴리시드 프로덕션 | 달콤한 멜로디, 감정적 깊이, 스트링 편곡 |
| 보컬 | 밝고 폴리시드, 전면 배치 | Sweet/Warm/Mature, 부드러운 리드 |
| 리드 악기 | 폴리시드 클린 일렉기타 | 스윗 피아노 멜로디 리드 |
| 피아노 역할 | **Chord bed only (리드 아님)** | **Lead melody instrument** |
| 기타 역할 | **Lead (bright clean riff)** | **Minimal or absent** |
| 스트링 | Pad layer (보조) | Rich arrangement (메인 질감) |
| 이펙트 | Moderate, 폴리시드 | Moderate, intimate studio |
| 곡 구조 | 명확한 V-PC-C-B, 라디오 프렌들리 | V-PC-C-B, 감정 아크 강조 |
| BPM | 95-118 (중심 100-114) | 86-102 (중심 90-100) |
| 13-00 적합도 | **메인 베이스 (65%)** | **질감 (20%)** |

### 2. 레퍼런스 곡 기반 증거

**마틴스미스 "봄 그리고 너" (Style A 직접 레퍼런스)**
- Melon 공식 장르: 댄스·인디음악 / Light Pop 병기
- BPM 98, C Major, 폴리시드 일렉기타 리프, 밝고 가벼운 프로덕션
- 편곡: Megatone (폴리시드 상업 팝)

**케이윌 "러브블라썸" (Style B 직접 레퍼런스)**
- 장르: Urban Soul / Funky Medium Pop (폴리시드 K-Pop)
- BPM 86 (하프타임), Db Major
- "Sweet piano + strings melody" 기반, 펑키 미디엄 비트
- 남성 라이트 테너, 달콤+성숙, G#4 벨팅

### 3. 한국 폴리시드 팝 고유 특성

- 깔끔한 믹싱 + 보컬 전면 배치 (인디 DIY 대비 폴리시드)
- 어쿠스틱/일렉기타 + 피아노 + 스트링 3층 구조
- Bright/Sweet/Polished 보컬 톤, 과한 처리 없음
- BPM 86-118, Major key 우세 (Minor 20%)

### 4. 13-00 혼합 공식

**Korean Light Pop (베이스 65%)** + **K-Pop Sweet Ballad (질감 20%)** + **Polished Pop Blend (완충 15%)**
= 마틴스미스 프로덕션 DNA × 러브블라썸 달콤 무드 × 혼합 완충

## Hard Gates (1개라도 FAIL = 재작성)

| # | Gate | 기준 |
|---|------|------|
| H1 | BPM | 86-118 범위 |
| H2 | Melody | 캐치한 멜로디 훅 존재 (인식 가능, 반복 시 각인) |
| H3 | Lead Instrument | 폴리시드 클린 기타(A/C) 또는 스윗 피아노 리드(B) |
| H4 | Vocal | 한국어 보컬 + 단독 리드 (Harmony Guard) |
| H5 | Tone | 밝고 따뜻한 폴리시드 톤 (DIY/aggressive/gritty 없음) |
| H6 | Structure | Verse-Chorus 구조 인식 가능 (Ambient drift 방지) |
| H7 | Exclude | Exclude 키워드 준수 + Articulation 포함 |

**Exclude 핵심 키워드** (Indie DIY + Over-Polished Idol 양방향):
- `lo-fi DIY texture, indie garage sound, noisy production`
- `jangly reverb bleed, room noise, raw demo quality`
- `idol group chant, EDM drop, sidechained synth, hyperpop vocal, autotune slide`

## Style-Specific Gates

### Style A — Korean Light Pop
| # | Gate | 기준 |
|---|------|------|
| A1 | Polished Clean Guitar | 폴리시드 클린 일렉기타가 리드 악기 (bright clean tone, light chorus) |
| A2 | Polished Medium Groove | 폴리시드 중간 그루브 드럼 (clean snare, soft hi-hat, radio-friendly) |
| A3 | Vocal Forward | 보컬이 믹스 전면, 선명하고 달콤 (Bright/Sweet/Polished) |

### Style B — K-Pop Sweet Ballad
| # | Gate | 기준 |
|---|------|------|
| B1 | Sweet Piano Lead | 스윗 피아노 리드 멜로디 존재 (grand piano, warm) |
| B2 | String Arrangement | 리치 스트링 편곡 존재 (배경 레이어 아닌 메인 질감) |
| B3 | Romantic Warm Mix | 로맨틱 따뜻 믹스 + 인티메이트 스튜디오 앰비언스 |

### Style C — Polished Pop Blend (혼합)
| # | Gate | 기준 |
|---|------|------|
| C1 | Guitar + Piano Balance | 클린 기타 리프 + 밝은 피아노 코드 공존 |
| C2 | String Bed | 스트링 베드 레이어 존재 (A의 pad와 B의 arrangement 사이) |
| C3 | Balance | 기타/피아노/스트링 3자 균형 (한쪽 지배 금지) |

## Drift 감지 체크리스트

Suno 결과물 청취 시 아래 신호가 감지되면 해당 Factor 감점:

### Indie DIY Drift (→ F5, F8 감점) — 강화
- [ ] 잔글링 기타가 지배 (lo-fi 질감, 클린 프로덕션 아님)
- [ ] 보컬에 룸노이즈/리버브 브리드 (폴리시드 아닌 raw)
- [ ] 드럼이 raw demo 품질 (폴리시드 아닌 garage)
- [ ] 전체적 DIY 느낌 (상업 믹스 아닌 bedroom 제작)

**탐지 키워드**: `lo-fi texture, jangly reverb bleed, room noise, raw demo quality, garage sound`

### Over-Polished Idol K-Pop Drift (→ F2, F8 감점) — 신규
- [ ] EDM 드롭 또는 댄스 빌드업
- [ ] Sidechained 신스 또는 과도한 컴프레션
- [ ] 오토튠 슬라이드 / 하이퍼팝 보컬 처리
- [ ] 아이돌 챈트 / group vocal 스택
- [ ] 4-on-the-floor 댄스 킥 패턴

**탐지 키워드**: `idol chant, EDM drop, sidechained synth, hyperpop vocal, autotune slide`

### K-Ballad Drift (→ F2, F6 감점)
- [ ] BPM <86으로 느려짐
- [ ] 피아노 발라드 구조 + 기타 완전 부재 (Style A/C 대상)
- [ ] 감정 과잉 (과도한 belt, 울먹임)
- [ ] 이별/상실 무드 (봄 톤 이탈)

### K-Pop Drift — 완화 (→ F8만 감점)
- [ ] 과도하게 처리된 보컬 (프로세싱 과잉)
- [ ] 아이돌 스타일 코러스 (13-00은 폴리시드 허용 but 아이돌 아님)

> **참고**: K-Pop Drift는 Light Pop이 폴리시드 팝이므로 엄격 기준 완화. "Over-Polished Idol"만 별도 상한선.

### City Pop Drift (→ F8 감점, 21-00 영역 침범)
- [ ] 레트로 신스 / 80s 팝 프로덕션
- [ ] 시티팝 특유의 펑키 베이스 + 코드 진행

### Ambient Drift (→ F1, F6 감점)
- [ ] 보컬 부재 또는 극히 미미
- [ ] 곡 구조(V-C) 소멸
- [ ] 멜로디 없이 텍스처만 존재

**2개 이상 체크 시:** 해당 Factor 재평가 + 프롬프트 조정
